# Currículo | Thomas Rangel Bugs

Portfólio e currículo web de **Thomas Rangel Bugs**, desenvolvedor Full Stack.

## Sobre

Site estático multi-página com apresentação profissional, escolaridade, idiomas, experiências e gostos pessoais. Inclui menu responsivo, animações leves, página 404 e build para publicação no Netlify.

## Páginas

- `index.html` — capa com foto, resumo e tecnologias
- `nivel_escolaridade.html` — formação
- `idiomas.html` — idiomas
- `experiencias_profissionais.html` — experiências e projetos
- `gostos_pessoais.html` — interesses pessoais
- `404.html` — página não encontrada

## Tecnologias

- HTML5
- CSS3
- JavaScript
- Netlify (`netlify.toml` + pasta `dist`)

## Como rodar local

1. Abra `index.html` no navegador **ou**
2. Execute o build e sirva a pasta gerada:

```bash
npm run build
```

A pasta `dist` fica pronta para deploy.

## Deploy (Netlify)

1. Conecte este repositório no Netlify **ou** arraste a pasta `dist` no Netlify Drop.
2. O `netlify.toml` já define o comando de build e o diretório publicado.
