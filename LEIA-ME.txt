COMO ABRIR O SITE
1. Extraia todos os arquivos do ZIP.
2. Abra a pasta "thomas_rangel_bugs".
3. Clique duas vezes no arquivo "index.html".
4. Use os links "Mais informações" para navegar entre as páginas.

ANTES DE ENTREGAR
- A foto pessoal já foi incluída no projeto.
- Confirme se os níveis de inglês informados estão corretos.
- Teste todos os links e o vídeo com a internet conectada.
- Grave um vídeo de até 3 minutos mostrando o site.

ROTEIRO SUGERIDO PARA O VÍDEO

1:20 a 1:40 - Mostre a página de idiomas e use o link de retorno.
1:40 a 2:10 - Mostre as experiências profissionais e os projetos.
2:10 a 2:40 - Mostre os gostos pessoais e reproduza alguns segundos do vídeo.

PUBLICAÇÃO NO NETLIFY
1. Envie este projeto para um repositório Git e conecte-o ao Netlify.
2. O arquivo netlify.toml já configura o comando e a pasta de publicação.
3. Para publicação manual, execute "npm run build" e arraste a pasta "dist"
   para o Netlify Drop.

O vídeo MP4 da apresentação permanece no projeto original, mas não é copiado para
"dist", pois não é usado nas páginas e arquivos grandes podem impedir o deploy.
